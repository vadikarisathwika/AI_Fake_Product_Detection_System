# AI-Based Fake Product Detection System

A beginner-friendly Streamlit + Machine Learning project for detecting suspicious online product listings.

## Features

- Product price comparison
- Product rating
- Review count
- Seller account age
- Seller verification
- Random Forest machine-learning model
- Genuine/suspicious prediction
- Probability score
- Simple risk-factor explanation

## Important

This is an educational prototype. The model is trained on small demo data and should NOT be used as proof that a real product is genuine or counterfeit.

## How to run

### 1. Open the project folder

```bash
cd AI_Fake_Product_Detection_System
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Start the Streamlit app

```bash
streamlit run app.py
```

The app will open in your browser.
